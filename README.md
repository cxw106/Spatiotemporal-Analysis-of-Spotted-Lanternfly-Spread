# Spatiotemporal Analysis of Spotted Lanternfly Spread

This repository contains the source code for a capstone project on the identification and spatiotemporal analysis of the spotted lanternfly (SLF, *Lycorma delicatula*).

The project consists of two main components:

1. **Image Classification (Python)**  
   A BioCLIP-based image classifier for distinguishing SLF from non-SLF images.

2. **Spatiotemporal Analysis (R)**  
   A Bayesian spatiotemporal analysis of SLF occurrence and spread in New York and Pennsylvania using R-INLA.
